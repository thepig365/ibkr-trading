{{ t('backtest.data_needed') }}

Backtests use local 1-minute candle data under data/candles/{SYMBOL}/1min/. If a ticker has no or partial files for your date range, the engine skips that name — a basket result may look like “only one symbol ran”. Check Data Coverage below only reads files (no IBKR). Use Fetch missing candles from IBKR one symbol at a time when you want to fill gaps.

{{ t('backtest.local_cache') }} — Fetched 1-minute candle data is cached locally so future backtests can run faster. These files stay on this machine under data/candles/ and are ignored by Git; they are not uploaded to GitHub.

One-click: coverage + optional IBKR fetch + backtest

Fetch Missing Data & Run Backtest will first read local 1m files (same as Check Data Coverage). If a symbol is Partial or Missing for the range, it will fetch 1m history from IBKR (read-only, no orders), then run the intraday backtest. It never places orders or starts paper/loop. Only click when TWS/IB Gateway is up if you need a fetch. If you prefer manual steps, use the three separate buttons above.
